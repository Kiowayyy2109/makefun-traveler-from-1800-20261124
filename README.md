One sentence, 156 characters, explaining the modern internet to someone
arriving from 1800 — built only from things they already know: a road, a
post office, a library. No word in it was coined after their time.

> Imagine one road joining every library and post office on earth, so a letter crosses the sea in a blink and a book from any shelf can be read at your table.

## Run it

```sh
python3 main.py
```

The program writes the sentence to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). It is deterministic: no input, no
randomness, no network, no clock — the same bytes on every run. Python 3
standard library only.
